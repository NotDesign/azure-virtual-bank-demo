# 最後檢查與未完成事項

## 此次原型已補

- 兩個跨分支完整客戶案例，固定交易、外鍵與每案 ledger；移除大量隨機資料。
- Canonical actor／scope、無權角色路由、直接案件／客戶 ID、跨分支變更與代看客戶訊息檢查。
- L1 的客戶申請入口改用自己有效邀請，L2 代客開關／凍結／父級狀態均檢查。
- 客戶移轉／代理移動的父子關係與價格下限檢查；歷史分潤快照。
- 公開申請、補件與代理申請在本機保存及跨分頁同步；原歸屬不漂移，舊公開快照不覆蓋審核。
- 外部單案指派、白名單快照、補件／駁回／通過、回覆去重、過期／撤銷／修訂失效。
- 審核通過與實際開戶分開；只有另行模擬開通回覆才新增虛構帳戶。
- 新增公開資料進入後台顯示時的 HTML escape，以及必要的直接操作 guard。

完整通過數與實際覆蓋以交付根目錄 `verification/` 報告為準；不得用單一元件通過推論全系統生產安全。

## P0：正式上線前必須實作

1. **真正後端登入與逐請求授權**：現有帳密、OTP、記住帳號、路由及 scope 均為前端演示。靜態原始碼包含兩筆種子，瀏覽器程式／儲存區可被使用者修改。
2. **正式申請與審單服務**：IndexedDB／localStorage 只能同瀏覽器同步。跨裝置、渠道身份、單案 token、不可竄改審計、版本交易及 webhook 驗簽／冪等須由服務端實作。
3. **外部附件權限**：外審目前分享虛構文件摘要／提交清單，沒有正式客戶原件下載；需受控物件儲存、惡意檔案檢查與短效授權 URL。
4. **正式 KYC／企業 KYB／AML**：智方便尚未取得沙盒、ITE 或生產接入；一般證件、活體、人臉與名單查核也都是示範。牌照類型未定，正式流程與供應商評估須另定。
5. **真實銀行、資金與 USDT**：沒有銀行開戶／扣款、鏈上入金、私鑰託管、正式匯率報價執行、對帳或雙式分錄；切勿把 Demo 餘額當成真實帳務。
